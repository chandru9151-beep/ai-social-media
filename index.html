Student Full-Stack Architecture & API Guide

Click to explore the request lifecycle, security, and prompt engineering.

▼

1. Client-Side Input & Validation

The form sanitizes inputs, enforces length boundaries (3–500 chars), and dispatches an asynchronous POST /api/generate-captions JSON request using the browser's native Fetch API.

2. Express REST API & Security

The Node/Express backend verifies allowed dropdown values, applies IP rate-limiting, and ensures the secret ANTHROPIC_API_KEY is never exposed to the client or browser.

3. Prompt Engineering & Claude

A specialized system prompt directs Claude to return structured JSON containing 3 distinct caption strategies (Hook & Story, Direct, and Engagement) tailored for the requested platform and language.

4. Clipboard & Regeneration

The UI leverages the modern Clipboard API with toast feedback, and permits individual card re-prompting via POST /api/regenerate-caption without re-generating all cards.
